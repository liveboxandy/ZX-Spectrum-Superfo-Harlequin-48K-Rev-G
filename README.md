This is a Kicad 10 project and was only used to create an ibom to assist in the debugging of faulty boards. Use at your own risk.

This was done by Importing the Orcad files into Altium, saving as Altium files and then importing those files into Kicad.

I have not created any Gerbers from this and would advise anyone to use the original gerbers.

I found the Orcad files at https://8bit-wiki.de/Sinclair/ZX_Spectrum/_zx48/SONSTIGES/harlequin/harlequin_rev-g.zip

The zip file also contains gerber files. I do not know if these are the original gerbers that are on PCBWay.

More information is available at https://8bit-wiki.de/Sinclair/ZX_Spectrum/_zx48/SONSTIGES/harlequin/ including a binary file of the ROM as well as information on building the Rev F.

Have fun.
